# IELTS Website using React (Vite)

A modern, responsive IELTS institute website built using **React + Vite**.
The project follows a modular component architecture with a strong focus on clarity, maintainability, and smooth user experience.

---

## 🚀 Tech Stack

* React (Component-based architecture)
* Vite (Fast build tool & dev server)
* CSS + Bootstrap (Responsive layout & styling)

---

## 📦 Setup Instructions

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run locally (Vite dev server)

```bash
npm run dev
```

### 4️⃣ Build for production

```bash
npm run build
```

### 5️⃣ Preview production build

```bash
npm run preview
```

---

## 🎨 Design Choices

* **Component-Based Structure**
  Navbar, Hero, Cards, Footer, and other sections are separated into reusable components.

* **Responsive Layout**
  Bootstrap grid system ensures proper alignment across devices.

* **Minimalistic UI**
  Focused on simplicity, clarity, and elegance.

* **Color Palette Used**

  * Cream — `#F4FEC1`
  * Mindaro — `#D9F9A5`
  * Citron — `#D2D68D`
  * Wenge — `#68534D`

* **Asset Management**
  Images and icons are stored locally for faster loading and easier updates.

* **Subtle Animations**
  Lightweight animations enhance visual appeal without affecting performance.
